# To-Do List Web App

Simple and responsive web application to manage tasks: add, complete, and remove to-dos.

---

## 🛠️ Technologies Used

- **Frontend**: HTML, CSS, JavaScript  
- **Framework / Tooling**: Vite, React.js  
- **Build / Lint**: ESLint (optional configuration)  
- **Dependencies**: Project structure via npm / package.json  

---

## 🚀 Features

- Add new tasks  
- Mark tasks as complete / incomplete  
- Delete tasks  
- Responsive layout that works well on mobile and desktop  
- Clean and simple UI for ease of use  

---
